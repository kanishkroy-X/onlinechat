# Google Search Console — Indexing & SEO Action Plan

## Overview

Current report:

| Status | Pages | Priority |
|---|---:|---|
| Alternate page with proper canonical tag | 1 | 🟢 Normal |
| Discovered — currently not indexed | 13 | 🟡 Investigate |
| Crawled — currently not indexed | 3 | 🟠 Investigate |
| **Total excluded** | **17** | |

**Goal:** Do not force every URL into Google. Ensure valuable public pages are indexable while private, temporary, duplicate, and application URLs stay out of search.

---

## 1. Alternate Page With Proper Canonical Tag

**1 page**

This is normally not an error. Google found an alternate/duplicate URL and selected another URL as canonical.

### Action

Verify that:

- The intended canonical URL is correct.
- The canonical page returns HTTP 200.
- The canonical page is accessible.
- The canonical URL is internally linked.
- The canonical URL is in the sitemap.
- Duplicate URLs are not unnecessarily used in internal links.

Do **not** try to eliminate this status just to make the excluded count zero.

---

## 2. Discovered — Currently Not Indexed

**13 pages**

Google knows these URLs exist but has not currently indexed them.

Open:

**Google Search Console → Page indexing → Discovered — currently not indexed → View affected URLs**

Classify every URL.

### Category A — Important public SEO pages

Examples:

```text
/
/random-chat
/random-text-chat
/random-voice-chat
/talk-to-strangers
/anonymous-chat
/safety
/about
/pricing
/blog/...
```

These should generally be:

- Public
- Crawlable
- Indexable
- Canonical
- HTTP 200
- In the sitemap
- Internally linked

### Category B — Private/application pages

Examples:

```text
/login
/signup
/dashboard
/settings
/profile/edit
```

These generally do not need Google indexing.

### Category C — Temporary/dynamic chat pages

Examples:

```text
/chat/12345
/match/987654
/room/abc123
/user/random-id
```

These generally should **not** be part of the SEO index.

Do not create an indexable URL for every random chat session or room.

---

## 3. Crawled — Currently Not Indexed

**3 pages**

Google successfully crawled these URLs but did not select them for indexing.

Inspect each individually instead of repeatedly requesting indexing.

### URL Inspection checklist

Verify:

- HTTP status = 200
- Page is accessible
- `noindex` is absent where indexing is intended
- robots.txt does not block crawling
- Canonical is correct
- Content is useful and unique
- Page is not a duplicate
- Page has internal links
- Page is in the appropriate sitemap
- Google can render the main content

---

## 4. Content Quality

A technically valid page can still be excluded.

Avoid thin pages such as:

> Random Chat — Start chatting with strangers.

Important landing pages should explain:

- What the service does
- How matching works
- How to start
- Privacy
- Safety
- Blocking/reporting
- Supported devices
- Supported languages
- FAQ

For example, **Random Voice Chat** should be a real landing page with useful information and a clear CTA, not just a keyword page.

---

## 5. Recommended SEO URL Architecture

Separate SEO pages from application pages.

### Indexable SEO pages

```text
/
/random-chat
/random-text-chat
/random-voice-chat
/talk-to-strangers
/anonymous-chat
/safety
/about
/pricing
/faq
/blog/...
```

### Application pages

```text
/app
/chat
/match
/room
/settings
/profile
/login
/signup
```

Application/session pages should generally not be part of the SEO strategy.

---

## 6. Sitemap Strategy

The sitemap should contain **canonical public pages that you actually want indexed**.

Good:

```text
/
/random-chat
/random-text-chat
/random-voice-chat
/safety
/faq
/about
/blog/...
```

Avoid:

```text
/chat/*
/match/*
/room/*
/settings
/login
/signup
/user/*
```

Do not use the sitemap as a dump of every URL generated by the application.

---

## 7. Internal Linking

Important SEO pages should be reachable from the homepage.

Recommended structure:

```text
Homepage
│
├── Random Chat
│   ├── Random Text Chat
│   └── Random Voice Chat
│
├── Safety
├── FAQ
├── About
└── Blog
```

The application should sit behind the landing pages:

```text
SEO Landing Page
       │
       ▼
   Start Chat
       │
       ▼
   Application
       │
       ├── Text Chat
       └── Voice Chat
```

---

## 8. Canonical Rules

Each indexable page should have one clear canonical URL.

Example:

```html
<link
  rel="canonical"
  href="https://example.com/random-voice-chat"
/>
```

Avoid:

- Multiple canonical tags
- Canonical pointing to unrelated pages
- Canonical chains
- Canonical URLs returning 404
- Canonical URLs blocked from crawling
- Inconsistent internal URLs

---

## 9. Dynamic URL Protection

This is especially important for a random chat platform.

Do not allow thousands of crawlable URLs such as:

```text
/chat/abc123
/chat/abc124
/chat/abc125
/chat/abc126
```

or:

```text
/room/user-a-user-b
```

Temporary chat sessions should preferably exist as application state rather than permanently indexable public pages.

---

## 12. Validation Workflow

After changes:

1. Deploy the changes.
2. Open Google Search Console.
3. Use **URL Inspection** for important pages.
4. Run **Test Live URL**.
5. Verify:
   - Crawling allowed
   - Indexing allowed
   - Canonical correct
   - Page accessible
6. Request indexing only for important pages where appropriate.
7. Submit/update sitemap.
8. Monitor the Page Indexing report.

Do not expect the report to update immediately.

---

## 13. Success Criteria

The target is **not**:

```text
17 excluded → 0 excluded
```

The target is:

```text
Important SEO pages
        ↓
Crawlable
        ↓
Indexable
        ↓
Canonical
        ↓
Indexed
        ↓
Search impressions
        ↓
Organic visitors
        ↓
Chat starts
```

A healthy website can have excluded URLs.

What matters is whether the **right URLs** are indexed.

---

## 14. Final Recommendation

For the random text + random voice chat platform:

> **Keep the SEO surface small, intentional, and high quality.**

Use Google to discover the product through a handful of strong landing pages.

Do not expose temporary chat rooms, matchmaking sessions, private user pages, or application state as indexable content.

### Immediate workflow

1. Inspect the **13 discovered URLs**.
2. Inspect the **3 crawled-but-not-indexed URLs**.
3. Classify every URL as **INDEX / NOINDEX / IRRELEVANT**.
4. Fix technical issues on pages that should rank.
5. Improve thin pages instead of repeatedly requesting indexing.
6. Keep the sitemap restricted to canonical public pages.
